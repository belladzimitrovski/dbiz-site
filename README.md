GitHub בונה מחדש את האתר תוך כ-1–2 דקות. **חשוב:** יש לרענן בדפדפן עם `Ctrl+F5`

## תוכן ומרכיבים

**מבנה הדף (לפי הסדר)** — לפי מסמך הקופי `כתיבת תוכן לאתר.docx` (אוקטובר 2026):
פתיח במסך אחד: מקטע מתחלף של 4 מקרי "הם רואים / אתם רואים", ומתחתיו "נקודת מבט של לקוחות..." כהערת שוליים קטנה (סבב 4).
המילים "הם" ו"אתם" קבועות ושאר כל שורה מוקלד (השורה השנייה בטורקיז); איור הנקודות בצד שמאל מתחלף בכל מקרה; במעבר בין מקרים הטקסט נמחק אות-אות ומוקלד מחדש (`script.js`, מערך `CASES`) ←
הכאבים בטור אחד על רקע מנטה רך (`.band-soft`), המשפטים המודגשים עם נקודה צבעונית גדולה (`.dot-punch`), פותח ב"אתם בעלי העסק, ואתם רואים..." (סבב 4; דוגמת הקליניקה ו"וזאת בדיוק הנקודה" הוסרו) ←
הפתרון במסך מלא באותיות גדולות מאוד (`.solution-big`) ← עליי + רובוט עם בועת דיבור ← 6 השאלות ("הלידים?" וכו') כרשימה מסומנת במרקר צהוב/טורקיז, האחרונה מוקפת בעיגול ביד (`.qa-list`, `.mark`) + "יש עוד שאלות" ←
"אני מאמינה" ← אינסוף אפשרויות (12 כרטיסיות + רצועת כלים) ← למה אני (3 עסקים "מנוקדים") ← איך עושים את זה (4 נקודות על "דרך": קו מנוקד וסיכת מיקום בכל שלב, `.road`; בטלפון שביל אנכי) ←
המלצות (קרוסלה) ← לוגואי לקוחות ← צרו קשר (קפה + טופס; אחרי שליחה קופץ רובוט) ← פוטר.
הלוגו בהדר יושב בצד שמאל עם שורת המיצוב "אוטומציה עסקית בהתאמה אישית" מתחתיו.

**העיצוב: "נקודות" (מאוקטובר 2026)** — נבחר מתוך 4 כיווני עיצוב (כיוון ד'). רקע שמנת `#fbfaf5`, דיו כהה `#14211f`,
נקודה צהובה `#ffd84d` ונקודה טורקיז `#1fb5b0`; כותרות, משפטי הפתיח, כפתורים ותוויות ב-Fredoka (מעוגל, עם משקלים אמיתיים 400–700), טקסט רץ ב-Heebo — שני גופנים בלבד; כרטיסים לבנים עם מסגרת כהה
2px; כפתורים בדיו כהה עם טקסט צהוב (במצב כהה — הפוך). הכאבים על פס כהה עם הדגשה צהובה, ההמלצות על פס צהוב.
ברירת המחדל היא מצב בהיר (`data-theme="light"`); מצב כהה נשאר בכפתור.

**איורי המקרים בהירו** — כל עסק מצויר כולו מנקודות בגדלים שונים (חצי-טון): כיסאות, לחם, משקולת, שעון.
נוצרים ב-[`tools/dotart.js`](tools/dotart.js) מצורות פשוטות (מלבנים, עיגולים, אליפסות) שממולאות ברשת נקודות;
את הפלט מדביקים לתוך `.case-stage` ב-`index.html`. כשמקרה מתחיל, הנקודות "קופצות" מהמרכז החוצה, ונקודות נוספות
ממשיכות לזוז (דברים נופלים בין הכיסאות, פירורים, זיעה, חול נשפך מהשעון, המחוגים רצים). רק המקרה הפעיל רץ.

**לחזור לעיצוב הקודם** (טורקיז כהה עם צילומי חנויות מונפשים ברקע ההירו): הוא שמור ב-GitHub כענף
`design-teal-cinemagraph` וכתגית `design-teal-2026-10-21`. לחזרה: `git checkout design-teal-cinemagraph`, או למזג
אותו ל-`main` ולדחוף. נוסו ונפסלו לאורך הדרך: אימוג'י, איורי SVG מלאים, תמונות במסך מלא, צילומים במסגרת.
**בועות הרובוטים מוקלדות** (`.tl` לכל שורה, `data-pause` להשהיה, `data-after` לאלמנט שמופיע בסוף).
**שימו לב:** הרשת כאן מסוננת — תמונות עם אנשים מגיעות מפוקסלות. הורדה מ-Node עובדת עם `node --use-system-ca`.

**הכלים בסקשן המערכות:** Make, Origami, Fireberry, Zoho, Airtable, n8n, Claude, SUMIT.
חמישה מהלוגואים רשמיים (מחבילת `simple-icons`); Origami ו-Fireberry חולצו מקבצי מקור.
הסמל של Fireberry מתחלף עם הערכה (שחור בבהיר, לבן בכהה) דרך `class="mono"`.
הסמל של SUMIT חולץ מבאדג' ה"powered by" של סמיט; כיוון שהוא נייבי כהה, הוא מורכב
כטוקן עגול (הסמל על מדליון עגול לבן, אפוי לתוך ה-PNG) כדי להישאר גלוי בשתי הערכות.

**לקוחות (רצועה + המלצות):** המרכז/עלי באר, ישיבת היכל יוסף, שוורץ תכשיטים,
שלמי שמחה, פלטיניום, Klass, אלפון ערד, אביטל שוורץ (החליפה את Aquarelle). כל הלוגואים על לוחית לבנה.
לוגו אלפון ערד הוחלף (אוקטובר 2026) בלוגו החדש "אלפון אנ״ש גור ערד", בלי השנה ובלי מספר הגיליון.

**המלצות (8 בקרוסלה):** 4 עם שם+לוגו (ציפי אולמן, היכל יוסף, גב' קפלן, Klass)
ו-4 אנונימיות (בלי שם). הקרוסלה נגללת הצידה עם חיצים ונקודות; במובייל — כרטיס אחד בהחלקה.

## פייפליין תמונות (לעיבודים עתידיים)

הרובוטים מגיעים מ-ChatGPT עם רקע סטודיו. הסרת הרקע נעשית עם מודל **ISNet** (ארוז בחבילת
`@imgly/background-removal-node`) שרץ דרך `onnxruntime-web` (WASM — כי חסר VC++ runtime
לבינארי הנייטיב). הסקריפטים בתיקיית ה-scratchpad של הסשן: הרצה, סתימת חורים בגוף,
סגירת "נגיסות" בקצה (morphological closing), הקטנה לגודל תצוגה, וחיתוך שוליים.
לוגואים וקטוריים (PDF) מרונדרים עם `pdfjs-dist` בתוך Chrome ואז נחתכים.
