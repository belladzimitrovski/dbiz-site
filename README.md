## איך מעלים עדכון לאתר (הכי חשוב)

האתר מתעדכן דרך git. אחרי כל שינוי בקבצים:

```bash
git add -A
git commit -m "תיאור השינוי"
git push
```

GitHub בונה מחדש את האתר תוך כ-1–2 דקות. **חשוב:** יש לרענן בדפדפן עם `Ctrl+F5`
(רענון רגיל טוען לוגואים/תמונות מהמטמון).

**הערות טכניות למי שממשיך:**
- טוקן GitHub של החשבון `belladzimitrovski` כבר שמור במחשב (credential manager), אז `git push`
  עובד בלי להזין סיסמה.
- בסביבה הזו `curl` נכשל מול github.com (בעיית TLS) ומחזיר `000` — זה **לא** אומר שאין רשת.
  `git` עצמו עובד מצוין. לבדיקת האתר החי משתמשים בדפדפן (Puppeteer), לא ב-curl.
- לבדיקת סטטוס הבנייה של Pages: `GET https://api.github.com/repos/belladzimitrovski/dbiz-site/pages/builds/latest`
  (עם `Authorization: Bearer <token>`). סטטוס `built` = עלה.

## פייפליין תמונות (לעיבודים עתידיים)

הרובוטים מגיעים מ-ChatGPT עם רקע סטודיו. הסרת הרקע נעשית עם מודל **ISNet** (ארוז בחבילת
`@imgly/background-removal-node`) שרץ דרך `onnxruntime-web` (WASM — כי חסר VC++ runtime
לבינארי הנייטיב). הסקריפטים בתיקיית ה-scratchpad של הסשן: הרצה, סתימת חורים בגוף,
סגירת "נגיסות" בקצה (morphological closing), הקטנה לגודל תצוגה, וחיתוך שוליים.
לוגואים וקטוריים (PDF) מרונדרים עם `pdfjs-dist` בתוך Chrome ואז נחתכים.
